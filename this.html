JS this 核心八股速查

高频必背背诵模板

八股 01

this 的指向到底是怎么决定的？（核心口诀）

标准回答：this 的指向不是在定义时决定的，而是在函数运行时决定的（箭头函数除外）。主要有以下 4 种绑定规则，优先级从高到低为：

1. new 绑定：如 new Foo()，this 指向新创建的实例对象。
2. 显式绑定：通过 call / apply / bind 强行绑定，this 指向指定的第一个参数。
3. 隐式绑定：通过对象方法调用，如 obj.foo()，this 指向上下文对象 obj。
4. 默认绑定：独立函数直接调用，如 foo()。非严格模式指向 window / global，严格模式指向 undefined。
💡 特例：箭头函数没有自己的 this，它会继承声明时外层最近的普通作用域的 this。
八股 02

call、apply、bind 三者的区别是什么？

标准回答：三者的共同点是：都能改变函数内部的 this 指向。核心区别在于执行方式与传参形式：

API 执行方式 传参形式
call 立即调用函数 参数列表，逐个传入（如 fn.call(obj, a, b)）
apply 立即调用函数 数组/类数组（如 fn.apply(obj, [a, b])）
bind 返回新函数，不立即执行 支持柯里化，可分步传参（如 fn.bind(obj, a)(b)）
八股 03

为什么箭头函数不能用作构造函数（不能 new）？

标准回答：如果对箭头函数使用 new 会直接报错，原因有以下三点：

1. 没有自己的 this：箭头函数的 this 是在定义时捕获外层作用域的，而 new 操作符的核心步骤是把新创建的对象绑定给函数的 this，箭头函数无法做到这一点。
2. 没有 prototype 属性：普通函数都有 prototype 显式原型，而箭头函数没有，因此无法挂载实例原型。
3. 没有 arguments 对象：箭头函数内部没有 arguments，只能用 rest 参数（...args）替代。
八股 04

什么是“隐式丢失”？怎么解决？

定义：当一个对象的方法被赋值给一个变量，或者作为回调函数传递时，方法会脱离原对象，变成“独立函数调用”，导致原本的隐式绑定失效，退化为默认绑定（指向 window 或 undefined），这就是隐式丢失。

常见场景：setTimeout(obj.fn, 1000) 或 var f = obj.fn; f();

解决办法：
1. 使用箭头函数包裹：setTimeout(() => obj.fn(), 1000)
2. 使用 bind 强行锁定：setTimeout(obj.fn.bind(obj), 1000)
