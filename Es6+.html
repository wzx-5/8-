一、什么是 ES6 / ES6+

概念

ES6 是什么？为什么叫 ES6+？

ES6 = ECMAScript 2015（ES2015），是 JavaScript 语言标准的一次历史性大版本更新， 于 2015 年 6 月正式发布。它带来了大量语法糖和新特性，是现代前端开发的基石。

为什么叫 ES6+：因为 ES6 之后 ECMAScript 改为每年发布一个版本 （ES2016、ES2017……），大家习惯把"ES6 及之后的所有新特性"统称为 ES6+，面试时统称 ES6+ 或 ES 新特性。
一句话定义：ES6+ 就是让 JS 更好写、更安全、更适合大型项目的一系列语法与 API 的集合， 核心围绕：块级作用域、函数增强、数据结构、面向对象、异步编程、模块化 六大方向。
💡 面试话术："ES6 是 2015 年发布的大版本规范（ES2015），它引入了 let/const、箭头函数、 Promise、class、模块化等核心特性；后续 ES2016~ES2022 又陆续补充了 async/await、可选链、空值合并、BigInt 等， 合称 ES6+。"

三、新特性详解与注意点

板块①

变量声明：let / const（块级作用域）

let：声明可重新赋值的块级作用域变量。
const：声明必须初始化、不可重新赋值的块级作用域常量。
// 块级作用域：花括号 {} 内才有效 { let a = 1; const b = 2; } // console.log(a) // ❌ ReferenceError：块外访问不到 // const 指针不可变，但内容可变 const arr = [1, 2]; arr.push(3); // ✅ 允许，改的是内容 // arr = [4] // ❌ 报错，不能重新赋值
⚠️ 三大注意点：
1. 暂时性死区（TDZ）：在声明语句之前访问 let/const 会报 ReferenceError；
2. 不允许重复声明：同一作用域内 let/const 不能与 var 或其他 let/const 重名；
3. const 必须立即初始化：const x; // ❌ 语法错误；且顶层 let/const 不会挂到 window 上（var 会）。
板块②

函数增强：箭头函数 / 默认参数 / rest / spread / 解构

箭头函数：更简洁的函数写法，不绑定自己的 this，继承外层作用域的 this。
默认参数：形参可设默认值，如 function f(a = 10) {}。
rest 剩余参数：...args 把多余实参收集成数组，替代旧的 arguments。
spread 展开：把数组/对象展开，如 Math.max(...arr)、{...obj}。
解构赋值：从数组/对象中按模式提取值，支持默认值、嵌套、交换变量。
// 解构 + 默认值 const { name = '匿名', age } = user; const [first, ...rest] = [1,2,3]; // first=1, rest=[2,3] // 交换变量（经典考题） [a, b] = [b, a];
⚠️ 注意点：
1. rest 参数必须是最后一个形参，且不能同时设默认值；
2. 箭头函数没有自己的 this / arguments / prototype，不能 new，也不能当生成器； 单行箭头函数不能换行（(a,b) => 必须同一行）；
3. 解构对象时等号右侧不能为 null / undefined（会报错），数组解构右侧必须可迭代；
4. 展开运算符做拷贝是浅拷贝，嵌套对象仍共享引用。
板块③

数据结构：Map / Set / WeakMap / WeakSet / Symbol / 迭代器

Set：值唯一的集合（天然去重），NaN 也视为相同。
Map：键值对集合，键可以是任意类型（对象、函数都可以），且保持插入顺序。
WeakMap / WeakSet：弱引用版本——键必须且只能是对象，不可遍历、无 size。
Symbol：生成唯一且不可变的值，常用于对象属性名防冲突、内置标记（如 Symbol.iterator）。
迭代器 / for...of：统一遍历接口，数组、Set、Map、字符串都可被 for...of 遍历。
// Set 去重（高频） const unique = [...new Set([1,1,2,3])]; // [1,2,3] // Map：键可以是对象 const m = new Map(); m.set(document.body, '页面');
⚠️ 注意点：
1. Set 判断重复用 SameValueZero，NaN === NaN 在 Set 里成立；
2. WeakMap 键必须是对象，否则抛 TypeError；弱引用意味着键对象被 GC 回收时，对应值自动消失， 适合做缓存/存储 DOM 节点/私有变量；
3. Symbol 每次调用都生成全新值，Symbol.for('x') 才能取到全局同一个 Symbol；
4. 对象不能直接 for...of，需用 Object.keys() / Object.entries()。
板块④

面向对象：class / extends / super

class：构造函数的语法糖，本质仍然是"函数 + prototype + 原型链"。
extends / super：实现继承；子类 constructor 中必须先调用 super() 才能用 this。
static：静态成员挂在类本身上，实例无法访问。
class Animal { constructor(name) { this.name = name; } speak() { return `${this.name} 叫`; } } class Dog extends Animal { constructor(name) { super(name); } } const d = new Dog('旺财');
⚠️ 注意点：
1. class 声明不会提升（有 TDZ），必须先声明再 new；
2. 类体默认是严格模式；类的方法不可枚举；
3. extends 本质仍是原型链继承 + 借用构造，子类实例同时链到 Sub.prototype 和 Super.prototype；
4. 子类不写 constructor 时默认调用 super(...args)。
板块⑤

异步编程：Promise / async / await / Generator

Promise：解决回调地狱的链式异步方案，三种状态 pending / fulfilled / rejected，状态一旦改变不可逆。
async / await：基于 Promise + Generator 的语法糖， 让异步代码像同步一样书写。
Generator：用 function* + yield 手动控制暂停/恢复，可被 for...of 遍历。
async function fetchData() { const res = await fetch('/api'); // 等待结果 const data = await res.json(); return data; }
⚠️ 注意点：
1. Promise 的回调是微任务，先于宏任务（setTimeout）执行；
2. await 只能在 async 函数内使用，出错需 try/catch 捕获；
3. 多个无依赖请求应使用 Promise.all 并行，而非逐个 await（串行慢）；
4. 箭头函数不能作为 Generator（不能 function*）。
板块⑥

模块化：import / export

命名导出 / 导入：export { a }，import { a } from '...'。
默认导出 / 导入：export default xxx，import xxx from '...'。
// a.js export const count = 1; export default function run() {} // b.js import run, { count } from './a.js';
⚠️ 注意点：
1. ES6 模块是编译时静态分析，import/export 必须写在顶层（不能写在 if 或函数里）；
2. import 的变量是"只读引用"（live binding），在导入方不能重新赋值，但能感知原模块内部变化——这与 CommonJS 的"值拷贝"不同；
3. 一个模块最多一个 default 导出，命名导出可多个；
4. 浏览器中需在 <script type="module"> 下使用。
板块⑦

扩展能力：Proxy / 可选链 / 空值合并 / BigInt

Proxy：拦截对象的 13 种基本操作（get、set、has、deleteProperty……）， 是 Vue3 响应式的基础。
可选链 ?.：安全访问深层属性，obj?.a?.b，为 null/undefined 时短路返回 undefined。
空值合并 ??：只在左侧是 null / undefined 时取右侧默认值，区别于 ||（对 0、''、false 也生效）。
BigInt：表示超过 Number.MAX_SAFE_INTEGER 的大整数，后缀 n。
const user = { info: { name: '张三' } }; const age = user?.info?.age ?? 18; // 18 const big = 9007199254740993n;
⚠️ 注意点：
1. ?? 与 || 或 && 混用必须加括号，否则报语法错误；
2. 可选链不能用于赋值左侧（a?.b = 1 报错）；
3. Proxy 不能拦截 == 比较；?? 判断标准是 null 与 undefined，0 和 '' 会被保留。

五、常考八股（背诵模板）

八股 01

var、let、const 三者有什么区别？

标准回答：三者的核心区别围绕作用域、变量提升、重复声明、能否修改四点，对比如下：

对比项 var let const
作用域 函数作用域 块级作用域 块级作用域
变量提升 有（初始化为 undefined） 有但存在 TDZ，声明前访问报错 有但存在 TDZ，声明前访问报错
重复声明 允许 不允许 不允许
初始值 可不初始化（undefined） 可不初始化（undefined） 必须初始化
挂载 window 会（全局声明时） 不会 不会
能否重新赋值 能 能 不能（引用不可变，内容可变）
💡 加分点："从使用优先级上讲，能用 const 就用 const，需要改值时用 let， 尽量不用 var（因为 var 的作用域和提升容易引发 bug）。const 保证的是绑定不可变，而不是值不可变。"
八股 02

什么是暂时性死区（TDZ）？

定义：在块级作用域内，let/const 变量从进入作用域开始，到声明语句执行之前 的这一段区域，称为暂时性死区（Temporal Dead Zone）。在这段区域内访问该变量会抛出 ReferenceError。

// 经典例子：typeof 也会报错（不同于 var） // console.log(typeof x); // ❌ ReferenceError let x = 1; // 经典陷阱题 var a = 100; { console.log(a); // ❌ TDZ，报错！ let a = 200; }
⚠️ 注意点：TDZ 的出现是因为 let/const 虽然存在变量提升，但提升后处于"未初始化"状态， 直到声明执行才绑定值。这也是 let/const 比 var 更安全的原因——能在早期发现"先使用后声明"的 bug。
八股 03

箭头函数与普通函数有哪些区别？

标准回答：核心区别在于箭头函数没有自己的 this，其余差异都是由此派生，共 6 点：

1. this 不同：箭头函数不绑定 this，this 继承自声明时外层最近的非箭头函数作用域， 且无法被 call/apply/bind 改变；普通函数的 this 在运行时由调用方式决定。
2. 不能作为构造函数：箭头函数不能 new，因为内部没有自己的 this 也没有 prototype。
3. 没有 arguments：箭头函数内部访问 arguments 会向外层找，需用 rest 参数 ...args 替代。
4. 没有 prototype 属性：普通函数有，箭头函数没有。
5. 不能做生成器：不能使用 yield。
6. 写法限制：返回对象字面量需加括号 () => ({a:1})；箭头和参数不能跨行。
💡 一句话记忆："箭头函数 = 简写 + 继承外层 this，适合做回调（setTimeout、事件、遍历）， 不适合做需要动态 this 的对象方法。"
八股 04

什么是解构赋值？有哪些经典使用场景？

定义：ES6 允许按照一定的模式，从数组或对象中提取值，并赋值给变量，这就是解构赋值。

场景 1：交换变量 —— [a, b] = [b, a]，无需第三个临时变量。
场景 2：函数参数解构 —— function f({name, age}) {}，直接提取对象字段。
场景 3：函数返回多个值 —— const [x, y] = getPoint();
场景 4：解构默认值 —— const {a = 10} = obj，当值为 undefined 时使用默认值。
场景 5：嵌套解构 + 重命名 —— const {a: {b: newB}} = obj
⚠️ 注意点：默认值只在值为 undefined 时生效（null 不生效）；解构右侧不能是 null / undefined；字符串可以按字符解构（const [a,b] = 'hi'）。
八股 05

展开运算符（spread）和剩余参数（rest）的区别？

标准回答：两者写法都是 ...，但作用方向完全相反：

对比项 剩余参数 rest 展开运算符 spread
作用 收集多个值 → 合成数组 展开可迭代对象 → 拆成单个值
使用位置 函数形参、解构中 函数调用实参、数组/对象字面量中
示例 function f(...args) {} Math.max(...arr)
// rest：把多余参数收集成数组 function sum(...nums) { return nums.reduce((p,c) => p+c, 0); } sum(1,2,3); // 6 // spread：把数组展开传入 / 拷贝 const copy = [...arr]; // 浅拷贝 const obj2 = { ...obj, a:1 }; // 对象浅拷贝 + 覆盖
⚠️ 注意点：rest 参数必须是最后一个形参；spread 展开数组是浅拷贝， 对象深层仍是引用；对象 spread 会调用 getter，且不能展开 null/undefined（对象展开 {...null} 在 ES2018 后不报错）。
八股 06

Promise 是什么？有哪些状态？四个静态方法有什么区别？

定义：Promise 是 ES6 提供的异步编程解决方案，代表一个尚未完成但未来一定会完成的操作， 用于解决回调地狱，让异步代码以链式方式书写。

三种状态：pending（进行中）→ fulfilled（已成功）或 rejected（已失败）；状态一旦改变就不可再变。
方法 触发条件 结果
Promise.all 全部成功才 resolve 任一个失败，整体立即 reject（快速失败）
Promise.allSettled 等待全部结束 无论成败都返回每个结果的状态数组（ES2020）
Promise.race 第一个 settle（成功或失败） 返回最先改变状态的 Promise 结果
Promise.any 第一个成功即可 全部失败才 reject（ES2021）
💡 加分点："Promise 解决的是回调嵌套问题，但本质上仍是回调，靠的是微任务队列 驱动状态回调。真正把异步写得像同步的是 async/await。"
八股 07

async/await 的本质是什么？它和 Promise / Generator 什么关系？

标准回答：async/await 是 Generator + Promise 的语法糖，本质上是 Promise 的进一步封装：

async 函数：始终返回一个 Promise；函数内 return 的值会成为该 Promise 的 resolve 值。
await 表达式：会暂停 async 函数执行，等待右侧 Promise 落定后恢复，并把结果作为表达式值。
与 Generator 关系：Generator 的 yield 是"手动暂停"，需要手动调用 next() 驱动；async/await 内置了自动执行器，配合 Promise 自动恢复，无需手动 next。
// 等价写法对比（概念上） // Generator 版 function* gen() { const a = yield fn1(); const b = yield fn2(a); } // async/await 版（内置执行器） async function af() { const a = await fn1(); const b = await fn2(a); }
⚠️ 注意点：await 只能在 async 函数内使用；并发场景要 await Promise.all([...])；await 出错会抛出，需 try/catch 或 .catch() 兜底。
八股 08

Set 和 Map 是什么？Set 如何实现去重？

Set：类似于数组，但成员值唯一，不重复。Map：类似于对象， 但键可以是任意类型且保持插入顺序。

Set 去重原理：Set 内部按 SameValueZero 算法判断是否重复，值为 undefined 的成员只能有一个； NaN 也能正确去重（虽然 NaN !== NaN）。
// 数组去重（经典一行） const arr = [1,2,2,3,3]; const unique = [...new Set(arr)]; // [1,2,3]
对比项 Map 普通对象 Object
键的类型 任意类型（对象、函数、NaN） 只能是字符串 / Symbol
键的顺序 保持插入顺序 整数键按升序，其余按插入序
size 大小 map.size 直接获取 需 Object.keys().length
遍历 可直接 for...of 需 Object.keys/entries
💡 加分点："需要频繁增删键值对或键不是字符串时用 Map； 需要把对象当结构化数据模型（JSON）用 Object。"
八股 09

WeakMap / WeakSet 与 Map / Set 的区别？有什么应用场景？

标准回答：WeakMap / WeakSet 是弱引用版本，核心区别有四点：

1. 键必须是对象：WeakMap 的键、WeakSet 的值只能是对象（不能是原始类型）。
2. 弱引用（不会被 GC 阻止）：当键对象不再被其他地方引用时，会被垃圾回收自动清除， 防止内存泄漏。
3. 不可遍历：没有 keys/values/entries 方法，不能 for...of，也没有 size 属性。
4. 可用方法少：WeakMap 只有 get/set/has/delete，WeakSet 只有 add/has/delete。
💡 典型应用场景：
1. 给 DOM 节点缓存关联数据，节点移除后数据自动释放；
2. 类中保存私有属性（不暴露、可被 GC）；
3. 避免"对象当 key 但对象已不用，却仍被 Map 强引用住"造成的内存泄漏。
八股 10

Symbol 是什么？有什么作用？

定义：Symbol 是 ES6 新增的第 7 种原始数据类型（其余：string/number/boolean/null/undefined/bigint）， 表示唯一且不可变的值。

1. 生成唯一标识：每次 Symbol() 都是全新值，Symbol('a') !== Symbol('a')。
2. 防止属性名冲突：作为对象属性名，不会与已有属性重名，适合做对象的私有/隐藏字段。
3. 内置 Symbol：如 Symbol.iterator（让对象可被 for...of 遍历）、 Symbol.toPrimitive（自定义类型转换）。
4. 全局共享：Symbol.for('key') 会返回全局唯一的同一 Symbol，配合 Symbol.keyFor 反向查询。
const s1 = Symbol('id'); const s2 = Symbol('id'); s1 === s2; // false，永远不相等 const obj = { [s1]: '隐藏数据' }; for (const k in obj) {} // Symbol 键不参与 for...in / Object.keys
⚠️ 注意点：Symbol 不能被 JSON.stringify 序列化；不能被 for...in / Object.keys 枚举（要用 Object.getOwnPropertySymbols 获取）。
八股 11

class 的本质是什么？和 ES5 构造函数有什么关系？

标准回答：class 本质上是 ES5 构造函数的语法糖， 底层实现依然是"函数 + prototype + 原型链"，并没有引入新的 OOP 模型。

// ES6 class class Foo { constructor(x) { this.x = x; } get() { return this.x; } } // 等价 ES5 写法 function Foo(x) { this.x = x; } Foo.prototype.get = function() { return this.x; }; // typeof Foo === 'function' // ✅ 两者类型都是函数
继承的本质：class Dog extends Animal 底层是 寄生组合式继承——子类实例的原型链 dog → Dog.prototype → Animal.prototype， 且子类构造中调用 super() 相当于调用父类构造函数。
⚠️ 注意点（与构造函数对比的差异）：
1. class 声明不提升，存在 TDZ；ES5 构造函数可以后调用；
2. class 内默认严格模式；类的方法不可枚举（ES5 prototype 方法可枚举）；
3. 不写 constructor 时默认 constructor(...args){ super(...args) }；
4. 类只能 new 调用，不能直接 Foo() 调用（会报错）。
八股 12

ES6 模块化（import/export）和 CommonJS 有什么区别？

标准回答：两者是两套不同的模块规范，核心差异在"编译时 vs 运行时""静态 vs 动态""拷贝 vs 引用"：

对比项 ES6 Module CommonJS
加载时机 编译时静态解析（依赖可静态分析、可 Tree-shaking） 运行时动态加载（require 是函数，可写在条件里）
导出方式 import / export，必须写在顶层 require / module.exports，任意位置
值的传递 只读的 live binding（引用），模块内部变了外部能感知 值拷贝 / 浅拷贝，内部变了外部不受影响
循环依赖 支持（靠静态绑定处理） 可能拿到未完成的对象，需谨慎
使用环境 浏览器 / 现代构建工具（打包时转译） Node.js（原生）
💡 加分点："ES6 模块因为编译时静态，所以可以做摇树优化 （Tree-shaking），去掉没被引用的导出；CommonJS 是运行时对象赋值，无法静态分析，这是前端打包 更倾向 ES6 Module 的根本原因。"
八股 13

for...of 和 for...in 有什么区别？

标准回答：一句话——for...in 遍历的是键（索引/属性名）， for...of 遍历的是值（元素）。

对比项 for...in for...of
遍历内容 可枚举属性名（键） 可迭代对象的值
适用范围 普通对象、数组的键 数组、Set、Map、字符串、arguments 等可迭代对象
对数组的键 输出索引（字符串 "0"、"1"） 输出元素值本身
原型链 会遍历原型链上的可枚举属性（需 hasOwnProperty 过滤） 不涉及原型链
普通对象 ✅ 可用 ❌ 报错（对象不可迭代，需 Object.keys/entries）
const arr = ['a','b']; for (const k in arr) { } // k = "0", "1"（索引字符串） for (const v of arr) { } // v = 'a', 'b'（值）
⚠️ 注意点：面试常考陷阱——for...in 遍历数组会把索引当成字符串， 且会带上原型链上可枚举属性（如手动扩展的 Array.prototype 方法），所以遍历数组优先用 for...of 或 forEach。
八股 14

Generator（生成器）是什么？yield 有什么用？

定义：Generator 是 ES6 引入的可以暂停和恢复执行的函数。用 function* 声明，函数体用 yield 交出执行权，调用返回一个迭代器对象。

执行机制：调用生成器函数不会立即执行，返回的是迭代器；调用 next() 才执行到下一个 yield 处并暂停，next(value) 传入的值会成为上一个 yield 的返回值。
function* gen() { const a = yield 1; const b = yield a + 1; return b; } const it = gen(); it.next(); // {value:1, done:false} it.next(10); // {value:11, done:false} a=10 it.next(20); // {value:20, done:true} b=20
💡 与 async/await 的关系：async/await 可看作是带自动执行器的 Generator—— Generator 需要手动 next 推进，而 async 函数内部帮你自动推进，且 await 后必须跟 Promise。 手动实现"Generator 自动执行器（co 库思路）"是常考的手写题。
⚠️ 注意点：箭头函数不能用作生成器（无 function* 写法）； 生成器函数内的 this 是生成器对象本身。

Proxy 和 Object.defineProperty 的区别？（Vue 响应式相关）

标准回答：Proxy 是 ES6 提供的元编程能力，可以拦截对象的 13 种操作； Object.defineProperty 是 ES5 的旧方案，两者能力差异巨大：

对比项 Proxy Object.defineProperty
拦截能力 13 种操作：get/set/has/deleteProperty/ownKeys… 只能拦截 get / set 两个
新增/删除属性 可监听（Vue3 响应式基础） 无法监听，需 Vue2 的 $set 辅助
数组变化 天然可监听（索引/长度变化） 无法监听，Vue2 需重写数组方法
嵌套对象 懒代理，按需递归 必须一次性递归所有属性（有性能与内存问题）
自身特性 作用于整个对象（返回代理） 作用于单个属性，不能监听整个对象
💡 加分点："这也是 Vue3 用 Proxy 重写响应式的核心原因——无需递归、 可监听新增删除、对数组友好、性能更好；而 Vue2 用 defineProperty 必须提前遍历属性， 新增属性无法自动响应，才需要 $set / $delete。"

可选链 ?. 和空值合并 ?? 的用法与区别？

可选链 ?.：当访问的中间对象可能为 null / undefined 时，短路返回 undefined，不再继续往下访问，避免 Cannot read properties of undefined 报错。

空值合并 ??：仅当左侧是 null 或 undefined 时，才返回右侧默认值； 而 || 对所有假值（0、''、false、NaN）都会取右侧。

const obj = { a: { b: 0 } }; obj?.a?.b; // 0 obj?.x?.y; // undefined，不报错 const n = 0; n ?? 10; // 0 （?? 保留 0） n || 10; // 10 （|| 把 0 当假值）
运算符 兜底条件 典型用途
?? 仅 null / undefined 数值/布尔默认值（0、false 是合法值）
|| 所有假值 传统默认值逻辑
⚠️ 注意点：?? 不能与 || 或 && 直接混用（a ?? b || c 语法错误），必须加括号；可选链不能用于赋值左侧。

浅拷贝和深拷贝的区别？如何实现深拷贝？

定义：浅拷贝只复制第一层，深层仍共享引用；深拷贝会递归复制所有层级， 与原对象完全独立。

常见浅拷贝方式：Object.assign({}, obj)、展开运算符 {...obj}、 Array.prototype.slice() / concat()。
常见深拷贝方式： JSON.parse(JSON.stringify(obj))（简单但有坑）、 structuredClone()（浏览器原生）、手写递归、lodash.cloneDeep。
方案 优点 缺点 / 局限
JSON 法 一行代码，简单 丢失 undefined/函数/Symbol/RegExp/Date（变字符串）、循环引用报错
structuredClone 原生、支持循环引用、Date/Map/Set 不支持函数、较新环境；兼容性需注意
手写递归 完全可控，可处理特殊类型 需处理循环引用（用 WeakMap 缓存）
// 手写深拷贝核心（处理循环引用） function deepClone(obj, map = new WeakMap()) { if (obj === null || typeof obj !== 'object') return obj; if (map.has(obj)) return map.get(obj); // 循环引用 const copy = Array.isArray(obj) ? [] : {}; map.set(obj, copy); for (const k in obj) copy[k] = deepClone(obj[k], map); return copy; }
⚠️ 注意点：面试常考"JSON 深拷贝的缺陷"：函数、undefined、Symbol、循环引用 都会被 丢失或报错，所以生产环境一般用 structuredClone 或 lodash。手写递归记得用 WeakMap 记录已拷贝对象防止死循环。
