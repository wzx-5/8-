⚡ 异步编程执行顺序 宏任务 vs 微任务

🔍 点击「运行测试」观察 同步代码 → 微任务(Promise) → 宏任务(setTimeout) 的固定执行顺序
// 经典面试题：输出顺序是什么？
console.log('① 同步 start');

setTimeout(() => {
  console.log('④ 宏任务 [setTimeout]');
}, 0);

Promise.resolve().then(() => {
  console.log('③ 微任务 [Promise.then]');
});

console.log('② 同步 end');
⏳ 点击「运行测试」查看异步执行顺序
同步任务 (立即执行) 微任务 (Promise/async) 宏任务 (setTimeout/I/O) ⏱ 执行顺序：同步 > 微任务 > 宏任务
🎯 校招核心结论： 即使 setTimeout 延时为 0，它也会被放入宏任务队列，必须等当前脚本中的所有同步代码和微任务队列清空后才会执行。 所以输出顺序永远是 ① → ② → ③ → ④。
