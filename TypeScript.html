概念与编译（3 题）

1. TS 和 JS 什么关系？为什么用 TS？🔥必考
TS 是 JS 的超集，在 JS 上加了静态类型系统，编译后变成 JS 运行，类型在编译期就被擦除，没有运行时开销。
  • 编译期发现错误（类型不匹配直接报错）；
  • IDE 智能提示、自动补全、重构更安全；
  • 多人协作时形成契约，大项目更可维护。
"超集 + 静态类型 + 编译期检查，运行时零开销。"
2. 简述 TS 编译过程？🔥必考
tsc 先做词法/语法解析 → 类型检查（有错就报，阻断生成）→ 类型擦除 → 输出 JS；浏览器只认 JS。
  • 类型检查在前，产物生成在后，编译错误会阻断输出；
  • Babel/SWC 只做转译不做类型检查（所以配 tsc --noEmit）；
  • Vite 项目：esbuild 转译 + tsc 检查，职责分离。
"检查在前、产物在后；Babel 只管转译，tsc 才管检查。"
3. 什么情况下 TS 不生成 JS？
开启 noEmit: true（或 tsc --noEmit）时只做类型检查；另外只有类型接口、类型别名的文件（.d.ts）也不会生成产物。
"类型是编译期产物，运行时全被擦除。"

类型辨析对比（10 题· 必背）

4. any 和 unknown 的区别？🔥必考
any 是逃生舱：放弃所有检查，随便赋值、随便调用；unknown 是安全版 any：可以接收任何值，但必须先收窄（typeof/守卫）才能使用，不能直接赋给别的类型。
"any 是裸奔，unknown 是上了锁；能用 unknown 不用 any。"
5. interface 和 type 的区别？🔥必考
interface 支持 extends 继承 + 声明合并；type 支持联合/元组/条件/映射等复杂类型但无声明合并。描述对象默认用 interface，需要复杂组合用 type。
  • 同名 interface 自动合并，type 重复声明报错；
  • type 能做 interface 做不了的：type A = string | number；
  • 两者都能描述对象、都能被 implements。
"接口能合并（extends），类型能计算（| / & / 条件）。"
6. 联合类型和交叉类型的区别？🔥必考
联合 A | B 是并集（取其一，用前需收窄）；交叉 A & B 是交集（同时满足，属性取并集）。
  • 交叉类型同名属性类型冲突时结果是 never；
  • 联合访问共同属性是安全的。
"| 是或（并），& 是且（交）。"
7. void 和 never 的区别？🔥必考
void 表示没有返回值（函数正常结束但不返回）；never 表示永远不会有值（抛异常、死循环），它是底部类型，可赋给任何类型。
  • never 常用于穷尽性检查（default 分支）；
  • never 能赋给一切，但没有东西能赋给 never。
"void 是'不返回'，never 是'回不来'。"
8. 类型断言 vs 类型守卫？🔥必考
断言（as）是欺骗编译器："我说它是它就是"，无运行时校验；守卫是用条件判断真实收窄类型，更安全。能守卫就别断言。
"断言靠嘴说，守卫靠判断。"
9. keyof 和 typeof 的区别？⚠️易错
keyof 作用在类型上，取对象键的联合（keyof User → "id"|"name"）；typeof 作用在值上，把值转成类型。
"keyof 取键名，typeof 把值变类型；合体：K extends keyof typeof obj。"
10. let 和 const 类型推断有什么不同？⚠️易错
let x = 3 推断为 number（可变，取宽）；const x = 3 推断为字面量 3（不可变，取最窄）。
"const 不可变，推断最窄的字面量；let 可变，推断宽类型。"
11. 数组和元组（Tuple）的区别？⚠️易错
数组长度不限、元素同类型（number[]）；元组定长且逐位定类型（[number, string]），越界访问报错。
  • [1, "a"] 未标注时推断为 (string|number)[]，不是元组；
  • 要元组必须显式写 [number, string]。
"元组是'定长定位的数组'，不写就不是。"
12. 枚举有哪些坑？⚠️易错
数字枚举会反向映射（Color[0]→"Red"），运行时占空间；字符串枚举无反向映射。建议用 const enum 或 const 对象代替。
"数字枚举双向映射占内存，字符串枚举单向。"
13. 可选链和空值合并是 TS 的吗？
不是 TS 专属，是 ES2020 的 JS 语法（?. 和 ??），TS 支持并对其有类型推断。?? 只兜底 null/undefined，|| 兜底所有假值。
"?? 只救 null/undefined，|| 连 0/'' 也救。"
C

泛型与高级类型（5 题）

14. 什么是泛型？有什么作用？🔥必考
泛型把类型当作参数（<T>），让函数/接口/类在不丢失类型安全的前提下复用，调用时自动推断。
  • 约束：<T extends HasLength> 限定必须有某属性；
  • 泛型运行时不存在，编译期擦除，不能 instanceof T。
"泛型 = 类型的参数化，要类型安全又要复用就靠它。"
15. 什么是条件类型？🔥必考
T extends U ? X : Y，类型层面的三元判断，根据类型关系分发结果。
"extends 判断 + 三元 = 条件类型。"
16. 什么是分布式条件类型？什么情况不触发？🔥必考
条件类型作用于裸类型参数且参数是联合时，会逐项分发：ToArray<string|number> → string[] | number[]。参数被包裹（[T]、T[]、Promise<T>）就不分发，整体判断。
"裸参联合才分发，包一层就不分（[T] extends …）。"
17. infer 关键字是干嘛的？🖊️手写常考
在条件类型的 extends 里声明待推断的类型变量并提取它：T extends Promise<infer U> ? U : T 解包 Promise。
  • ReturnType / Parameters / Awaited 都是 infer 实现的；
  • infer 只能出现在条件类型的 extends 子句中。
"infer 就是'抓一个未知类型出来'。"
18. 映射类型是什么？🖊️手写常考
[P in keyof T]: T[P] —— 遍历对象每个 key，逐属性转换类型。Partial/Readonly/Pick 全靠它。
"in keyof 遍历 = 映射类型。"
D

类 / 函数 / 模块（5 题）

19. 访问修饰符有哪些？private 和 JS 的 # 有区别吗？🔥必考
public / private / protected / readonly / static。TS 的 private 是编译期约束，运行时仍是普通属性（(obj as any).x 可访问）；JS 的 #x 是真正的运行时私有。
"TS private 只管编译期，JS # 才是真私有。"
20. 抽象类 vs 接口的区别？🔥必考
接口只有形状、无实现，编译期完全擦除；抽象类可以有实现、可继承，运行时存在。抽象类不能被实例化，抽象方法子类必须实现。
"接口只画图纸，抽象类还能给半成品。"
21. 函数重载怎么理解？⚠️易错
TS 重载 = 多个签名 + 一个实现，实现签名要兼容所有签名。它没有运行时机制，只是编译期多签名约束（不像 Java 有运行时多态）。
"签名在外、实现在下；纯编译期，无运行时。"
22. 什么是声明合并？
同名 interface / 命名空间 / 函数可自动合并到同一个类型上，常用于给第三方库补全局类型；type 不支持。
"同名 interface 自动'粘'在一起。"
23. .d.ts 文件是做什么的？🔥必考
类型声明文件，只含类型、不参与运行。三种情况需要：① JS 库无类型 → @types/xx 或手写 declare module；② 声明全局变量/类型 → declare；③ 资源文件（.png/.css）补声明。
"有 import 就是模块声明，要全局就 declare global。"
E

收窄与守卫（3 题）

24. 有哪些类型守卫？🔥必考
typeof（原始）、instanceof（类实例）、in（属性存在）、Array.isArray、=== 字面量判断、自定义类型谓词 (x): x is Fish。
"typeof / instanceof / in / isArray / 谓词，六选一。"
25. 什么是可辨识联合？🔥必考
联合的每个成员都有公共的、字面量类型的判别字段（kind/type），switch 这个字段就能精确收窄到对应分支。
  • 典型场景：异步状态 loading / success / error；
  • default 分支赋给 never 做穷尽性检查，漏分支就报错。
"每个成员带'身份证'（kind），switch 身份证精确收窄。"
26. strict 模式包含哪些？🔥必考
一组严格检查的总开关，核心是 strictNullChecks（null/undefined 不能随意赋值）、noImplicitAny（禁止隐式 any）、strictFunctionTypes、strictPropertyInitialization、noImplicitThis 等。
"null 检查 + 禁隐式 any + 函数逆变 + 属性初始化。"

手写题专区（面试必背代码）

这些是"现场手写"高发题，直接背源码。

🔨 属性操作类（映射类型）

Partial — 全部可选
type MyPartial<T> = {
  [P in keyof T]?: T[P];
};
Readonly — 全部只读
type MyReadonly<T> = {
  readonly [P in keyof T]: T[P];
};
Pick — 选指定 key
type MyPick<T, K extends keyof T> = {
  [P in K]: T[P];
};
Record — 键值对象
type MyRecord<K extends keyof any, V> = {
  [P in K]: V;
};
口诀：映射 = 遍历 key；可选加 ?，只读加 readonly，挑选加 K extends keyof T。

🎯 联合/函数提取类（条件类型）

Exclude — 从 T 剔除 U
type MyExclude<T, U> = T extends U ? never : T;
Extract — 提取 T 中属于 U 的
type MyExtract<T, U> = T extends U ? T : never;
ReturnType — 取返回类型
type MyReturn<T> =
  T extends (...args: any[]) => infer R ? R : never;
Unwrap — Promise 解包
type Unwrap<T> =
  T extends Promise<infer U> ? U : T;
口诀：Exclude 命中 never 剔除，Extract 命中保留；infer 在 extends 里抓类型。

🛡️ 可辨识联合 + 穷尽性检查（完整模板）

type State =
  | { status: "loading" }
  | { status: "success"; data: string }
  | { status: "error"; msg: string };

function render(s: State) {
  switch (s.status) {
    case "loading": return "加载中";
    case "success": return s.data;
    case "error": return s.msg;
    default:
      const _n: never = s; // 新增分支漏处理 → 编译报错
      return _n;
  }
}

易错点快筛（判断题一眼过）

面试官最爱从这些坑里出题，看到就打勾记住。

const vs let 推断：const 推断字面量，let 推断宽类型。
数组 vs 元组：[1,"a"] 推断为 (string|number)[]，不是元组。
交叉冲突：{a:string} & {a:number} 的 a 是 never。
数字枚举：反向映射占内存，字符串枚举没有反向映射。
断言无检查：as 只在编译期生效，运行时不会校验。
泛型运行时：编译期擦除，不能 instanceof T。
strictNullChecks：开之后 let s:string = null 报错。
TS private：是编译期约束，(obj as any).x 仍可访问；JS # 才是真私有。
分布式条件：裸参联合才分发，[T] extends 包起来就不分发。
泛型箭头函数：JSX 中要写 <T,>（加逗号）。
bigint 混用：1n + 1 类型错误，不能和 number 混算。
?? vs ||：?? 只兜底 null/undefined；|| 兜底所有假值（0/''）。
object ≠ {}：object 表示所有非原始类型，空对象 {} 范围更大。
函数重载：重载签名必须在实现签名之前。
